# Studybud 📚

Studybud is a web application designed to help students connect, create study rooms, and collaborate on various topics. 

## 🚀 Tech Stack
* **Backend:** Python (3.12+), Django 6.0
* **Database:** SQLite (Default) 
* **Frontend:** HTML, CSS, JavaScript 
* **CI/CD:** GitHub Actions

## ✨ Features
* **User Authentication:** Sign up, log in, and manage user profiles.
* **Study Rooms:** Create and join topic-based study rooms.
* **Real-time Activity:** (Add any specific features you are building, like live chat, forums, etc.)
* **Search & Filtering:** Easily find rooms and topics of interest.
